# Athena 界面风格

参考本地 Xike 的默认 BREATHE（呼吸）风格，保留 Athena 的日历、纪念日、倒数日三个入口以及现有编辑、搜索和设置操作。

- 浅色使用暖白背景 `#F8F7F2`、白色卡片和柔和的灰绿色层次；深色使用 `#121614` 背景和深绿灰表面。
- 默认使用鼠尾草绿；主题色为雾青、鼠尾草、晨曦橙、深海蓝、桃粉，保留系统／浅色／深色模式及 Android 动态取色设置。旧雾紫设置兼容映射为雾青。
- 页面标题采用 35sp／44sp 的衬线字体；分区标题采用 23sp／32sp，正文保持清晰的层级。
- `AthenaShapes` 统一卡片 28dp、内部控件 18dp、弹层 30dp 的圆角。
- 主内容左右边距为 20dp，日期卡片使用 16dp 内边距，底部导航使用整块圆角选中背景。
- 不修改日期计算、数据存储、提醒、导入导出或权限流程。

中文字体的实际字形由 Android 系统字体提供。Android 动态取色开启时，颜色遵循壁纸；系统生成紫色调时回退到所选主题色。排版和圆角仍保持本风格。
